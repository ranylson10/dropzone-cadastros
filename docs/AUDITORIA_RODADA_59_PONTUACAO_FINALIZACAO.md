# Rodada 59 — Pontuação, classificação, finalização e reabertura

Adiciona um cenário E2E controlado que cria campeonato, fase, grupo, vaga, inscrição e jogo temporários; grava uma súmula real; confere classificação e pontuador; finaliza a queda; verifica o bloqueio de edição; reabre a queda; e remove automaticamente toda a estrutura temporária.

O cenário usa o comando único já existente:

```bat
npm run testar:tudo
```

Cobertura adicionada em desktop e mobile, elevando o conjunto esperado de 50 para 52 testes.
