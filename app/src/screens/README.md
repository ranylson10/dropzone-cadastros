# Telas mobile

## V1 essencial

- `HomeScreen`: início por perfil, próximas ações e atalhos.
- `LoginScreen`: entrada com Google usando a mesma conta do site.
- `ProfileSwitcher`: troca de perfil ativo.
- `VacanciesScreen`: lista de campeonatos com vagas.
- `PurchaseClaimScreen`: compra/entrada guiada mantendo o campeonato selecionado.
- `MyChampionshipsScreen`: campeonatos vinculados ao perfil.
- `TeamRosterScreen`: equipe, lines e elenco.
- `LineupScreen`: escalação guiada com prazo por jogo.
- `AgendaScreen`: agenda por perfil.
- `InvitesScreen`: correio, convites e pedidos.
- `WalletScreen`: carteira e comprovantes.
- `SellerSalesScreen`: vendas assistidas do vendedor.
- `ProducerOverviewScreen`: painel rápido da produtora.
- `RankScreen`: rank inicial e contrato para futura API consolidada.
- `LiliScreen`: assistente conversacional.

## Regra de experiência

Se uma ação exigir configuração avançada, o app deve abrir a tela exata no site, não tentar recriar o painel completo no mobile.
